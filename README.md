# SlideSync AI

An intelligent AI-powered platform that helps software engineering instructors keep their lecture slides current with the latest industry trends. Built as an academic project at Prince Mugrin University (SE262).

## Problem
Software engineering evolves quickly, and instructors have little time to search for new tools and practices and fold them into their lectures.

## Solution
SlideSync AI analyzes uploaded lecture slides, extracts key topics, and uses Retrieval-Augmented Generation (RAG) to retrieve up-to-date information from trusted sources, without modifying the original slides.

## Key Features
- Secure instructor login (institutional email or SSO)
- Reusable project profiles: recency, preferred/excluded sources, summarization preferences, version history
- Upload and validate PDF, PPT, and PPTX slides (batch upload)
- AI-generated summaries linked to the relevant slides
- E-Slides: original slides side by side with editable AI update notes
- Confidence-based updates: high-confidence applied, low-confidence left for instructor review
- Clickable list of sources for every update
- Secure shareable links and PDF export of E-Slides
- Two-panel workspace: slide thumbnails and AI chat, plus summary/E-Slides/sources tools

## Tech
HTML, CSS, JavaScript (web interface), designed with the MVC pattern and UML models (Class, Sequence, Activity).
